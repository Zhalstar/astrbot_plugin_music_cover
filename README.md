# astrbot_plugin_music_cover

[![License](https://img.shields.io/badge/License-AGPL--3.0-blue.svg)](https://www.gnu.org/licenses/agpl-3.0.html)

`astrbot_plugin_music_cover` 是 `astrbot_plugin_music` 的附加插件。它复用音乐插件的搜索和下载接口，再调用同一台机器上的 RVC WebUI 完成人声分离与音色转换。

## 前置要求

1. 安装并启用 `astrbot_plugin_music`，版本需提供 `MusicApi v1`。
2. 在音乐插件中启用至少一个可用音源。
3. 启动 `RVC20240604Nvidia` 的 WebUI，默认地址为 `http://127.0.0.1:7897/`。
4. 确保 AstrBot 环境能够调用 FFmpeg。

插件不限制搜索音源，直接使用音乐插件配置的优先级和回退链自动选择，并通过 `MusicApi.download_audio()` 下载最终命中的歌曲。RVC 只接收本地音频文件，不再依赖网易云或 B 站歌曲 ID。

## 命令

| 命令 | 说明 |
| --- | --- |
| `/翻唱 <歌名>` | 搜索歌曲并选择全部翻唱参数 |

插件会在一条消息中同时显示歌曲、音色和参数说明。回复格式为 `歌曲序号 [音色序号] [高潮/全曲] [升降调] [大混响]`，例如 `1 2 全曲 -2 大混响`。音色序号省略时默认使用第一个音色；翻唱范围使用配置值（默认高潮），升降调默认为 `0`，大混响默认关闭。省略音色并指定正数升调时使用带符号写法，例如 `1 +2`。

选择高潮时，插件会根据所选歌曲的 LRC 重复段落定位副歌，并在分离和推理前截取片段。配置时长是期望值，实际结尾会优先对齐到附近的歌词行边界，再使用短淡出避免硬切。升降调范围为 `-12` 到 `12`；`大混响` 会为本次翻唱叠加较强的空间与回声效果。

无法可靠识别副歌时不会中断生成：有歌词时间轴时会选择歌曲约 55% 位置附近并对齐歌词行；没有有效时间轴时，会根据下载后音频的真实时长截取中后段。

生成流程为：音乐插件下载音频、按需截取高潮、RVC UVR5 分离人声和伴奏、加载所选音色并转换人声、同步变调伴奏、混音并发送。高潮模式只处理截取后的片段，因此会显著减少分离和推理时间。

## 配置

- 搜歌配置：候选歌曲数量和选择超时。
- 推理配置：推理超时、默认分离模型、默认翻唱范围、高潮片段时长、人声和伴奏音量。
- RVC WebUI：配置 WebUI 地址；音色和可用分离模型由插件初始化时自动刷新并保存。

地址保存后需要重载插件。插件直接兼容 RVC WebUI 使用的旧版 Gradio WebSocket 协议，不需要安装或启动 RVCSVC-API。RVC 的音色状态是全局的，因此插件会串行执行分离、加载音色和推理，避免并发任务串用模型。

音乐插件单独重载时，RVC 连接和已经进入推理阶段的任务不会关闭；依赖音乐接口的新搜索和下载会暂时提示重载中，并在音乐插件加载完成后自动接入新的 `MusicApi` 实例。

## 与旧版的区别

插件移除了内置的网易云/B站搜索、封面拼图、临时文件上传和 QQ 音乐卡片实现。音源配置统一由 `astrbot_plugin_music` 管理，翻唱结果使用 AstrBot 语音消息发送。

## 业务层复用

`service.py` 中的 `MusicCoverService` 不依赖消息事件，可供命令、WebUI 或其他 API 应用层复用。插件实例通过 `self.service` 暴露业务层，主要接口如下：

- `search_songs()`：通过音乐插件配置的优先级和回退链搜索歌曲。
- `resolve_chorus_clip()`：优先通过歌词定位副歌，失败时返回中后段兜底区间。
- `models()`：读取初始化时从后端刷新的模型。
- `initialize()` / `close()`：连接或关闭 RVC WebUI 客户端。
- `generate_cover()`：下载所选音源并完成裁剪、分离、RVC 转换和混音。
- `release_result()`：使用完毕后释放生成的临时音频。
